## About

I am a Computer Science student who learns by building from first principles. My work focuses on systems programming, high-performance CLI utilities, and developer tooling in **Rust** and **Go**. I am drawn to local-first software, applied cryptography, and cross-platform architecture where resource efficiency and data sovereignty matter.

---

## Current Focus

- **Systems & Terminal Runtimes:** Real-time terminal graphics, ANSI/Braille rasterization, and low-latency CLI tools in **Rust**.
- **Applied Cryptography & Privacy:** Zero-dependency encryption utilities with authenticated streaming ciphers (AES-256-GCM) and memory-hard key derivation (Argon2id).
- **Local-First Desktop Architecture:** Lightweight cross-platform desktop applications built with **Tauri**, native OS APIs, and embedded SQLite with zero telemetry.

### [ZenLavaTerm](https://github.com/githubuser2777/ZenLavaTerm)
Terminal-native lava lamp and metaball visualizer featuring real-time scalar potential field evaluation.  
`Rust` · `ANSI / Braille Rasterization` · `Criterion`  
*Focus: scalar field math · continuous-to-discrete rasterization · cross-platform packaging*

### [ZenSec](https://github.com/githubuser2777/ZenSec)
High-performance, zero-dependency command-line utility for authenticated file encryption and decryption.  
`Go` · `AES-256-GCM` · `Argon2id`  
*Focus: authenticated stream processing · anti-tampering chunk nonces · constant 64KB memory footprint*

### [ZenKeyCount](https://github.com/githubuser2777/ZenKeyCount)
Privacy-first desktop activity monitor tracking input cadence with native OS hooks and local storage.  
`Rust` · `Tauri v2` · `React` · `TypeScript` · `SQLite`  
*Focus: OS-level input hooks · IPC boundary design · zero-telemetry local analytics*

### [fetch-win](https://github.com/githubuser2777/fetch-win)
Animated 3D terminal fetch tool rendering ASCII distro logos as rotating point-clouds with native telemetry.  
`C` · `CMake` · `Win32 API`

### [ZenYT](https://github.com/githubuser2777/ZenYT)
Lightweight, hardware-accelerated desktop YouTube client and downloader wrapping `yt-dlp` and `ffmpeg`.  
`Rust` · `Tauri v2` · `React 19` · `yt-dlp`

### [ZenFlashCard](https://github.com/githubuser2777/ZenFlashCard)

`Flutter` · `Dart` · `SQLite`  
*Focus: SM-2 scheduling engine · granular review persistence · WCAG AA accessibility*

## Principles

- **Understand before abstracting:** Dive into fundamentals and OS primitives before adding layers.
- **Prefer simple architectures:** Minimal dependencies, clear data flow, and predictable execution.
- **Build small, testable components:** Strict boundaries with verifiable unit and integration tests.
- **Measure before optimizing:** Profile memory and CPU bottlenecks with benchmarks, not assumptions.
- **Leverage AI with discipline:** Treat AI as a force multiplier for execution, never a substitute for technical comprehension.
