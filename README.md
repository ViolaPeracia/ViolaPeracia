## `~/principles`

- **Understand before abstracting** — Master low-level mechanics before introducing high-level wrappers.
- **Prefer simple architectures** — Minimize external dependencies; prioritize transparent data flow.
- **Build small, testable components** — Compose systems from isolated units with explicit boundaries.
- **Measure before optimizing** — Rely on benchmarks and profilers rather than assumptions.
- **Tools amplify, understanding delivers** — Use modern tooling for velocity, but maintain complete ownership of every abstraction.
